# Scope of the MIT license

The LICENSE file covers the authors' own analysis software and its documentation. Shuo Yu confirmed this license choice on 2026-10-19.

It does not license third-party datasets, images, pretrained weights, model implementations or journal templates. This code candidate contains none of those assets. The full numerical reconstruction also requires separately licensed frozen inputs; the STheReO redistribution basis is still being checked. NSAVP dataset records identify CC BY 4.0, with provider attribution and processing notices required.

The locally verified numerical-candidate-v2 archive predates this license decision and retains its historical metadata templates. Its analysis source bytes match the code listed in CODE_MANIFEST.json. Its old license placeholders do not describe a final public release. The final numerical release must incorporate current licenses and metadata in a new version and pass retrieval and reconstruction from the actual public archive.
